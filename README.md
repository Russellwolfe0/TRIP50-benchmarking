## Aliases
In the original TRIP50 publication, the species
- 25-P2
- 28-R1
- 13-R1
- 42-R2

were treated as separate species, though there were canonical counterparts in the dataset. In this analysis, these species will be represented by their alias species, respectively:
- 10-P2
- 25-R2
- 10-R1
- 14-R2

as represented in `configs/aliases.csv`.
