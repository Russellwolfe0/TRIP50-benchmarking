Benchmarking Kinetic and Thermodynamic Energetic Predictions for Triplet Reactivity
Russell Wolfe

This study tests whether Machine Learning Interatomic Potentials (MLIPs) can recover the reference conformers of the TRIP50 structures when optimizations start from automatically generated RDKit conformers instead of the reference geometries.

GitHub Energy benchmark View results

Overview

The energy benchmark evaluates every method on the same fixed reference geometries from the TRIP50 data set.[1] In practice, a model is usually given a structure that has not been optimized at a high level of theory, and it must find a low-energy conformer on its own. This study asks whether the 16 MLIPs from the energy benchmark do that reliably for open-shell species.

Every non-transition-state species (106 of the 156 structures) was converted to a SMILES string, a conformer ensemble was generated from it, and each conformer was optimized with each MLIP. The lowest-energy result was then compared with the same model's optimization of the reference geometry.

Methods

Conformer generation

SMILES strings were generated from the reference XYZ geometries with Open Babel[4] and checked against the reference formulas and multiplicities. Five species needed manual correction because Open Babel does not assign formal charges: the azides (11-R1, 11-P2, 49-R1), the diazo ester 50-R2 and the PhSO2• radical 20-P1. Conformers were generated with the CSEARCH module of AQME[2] using RDKit[3], giving 553 conformers across 106 species (median 2 per species, maximum 25).

SMILES strings do not carry spin. Thirteen species are triplet excited states of closed-shell molecules, so charge and multiplicity for every optimization were taken from the TRIP50 metadata, not from the conformer files.

MLIP optimizations

Each conformer was optimized with each of the 16 MLIPs using the BFGS optimizer in ASE[5] (maximum force 0.05 eV/Å, at most 500 steps). Each model also optimized the original reference geometry, giving that model's own reference energy.

Comparison with the reference

MLIP energies are only meaningful as differences within one model, so each model's best conformer is compared with that model's optimized reference:

$$\Delta E = E_{\text{best conformer}} - E_{\text{optimized reference}}$$

Heavy-atom RMSD to the DFT reference was computed with RDKit after matching atoms by bonding graph. Each model and species is assigned one category, in this order:

CategoryRule
RearrangedBonding pattern (including H) differs from the reference
Not convergedBest conformer did not reach 0.05 eV/Å
Linear artifactMore near-linear (>170°) two-coordinate heavy-atom centres than the reference
Matches reference$|\Delta E| \le 0.5$ kcal/mol
Lower than reference$\Delta E < -0.5$ kcal/mol
Higher than reference$\Delta E > +0.5$ kcal/mol (reference conformer not recovered)

DFT checks

Where models found conformers below the reference, single points were run on the MLIP geometry and the reference geometry at ωB97M-V[6]/def2-QZVPP[7] in ORCA.[8]

Discussion

Fifteen of the 16 MLIPs recover the reference conformer for 62–74% of species, with AllScAIP-MD conserving (73.6%) and POLAR-1-l (72.6%) highest. eSEN-SM direct is the outlier at 49.1%: 244 of its 553 conformer optimizations did not converge. Its forces come from a separate output head rather than the gradient of the energy, and the noise in them prevents BFGS from settling.

Most failures share a few causes. Force-field starting geometries build some two-coordinate radical centres, such as acyl radicals, exactly linear, and BFGS started from that symmetric geometry stays on the saddle point. Some multi-conformer species were not sampled close to the reference conformer. Species below the reference are either real lower conformers or MLIP errors, and only a higher-level check can tell them apart.

The DFT checks show both cases. For 41-P1 and 24-P1 the MLIPs agree with DFT to within 0.1 kcal/mol, so the TRIP50 reference geometries are not the lowest conformers of those species. For 41-P1 the reference is the Z allyl radical connected to the C–Cl cleavage transition state, while the MLIPs find the E allyl. For 41-R1 and 24-R1 the MLIP conformers are higher than the reference at DFT, so the MLIP preference is an error. The reference single points did not include an SCF stability check.
