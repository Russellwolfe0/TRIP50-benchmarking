Benchmarking Machine Learning Potentials for Triplet Reactivity

This project benchmarks machine learning interatomic potentials on the TRIP50 dataset for triplet-state chemical reactions.

Models Tested

  • ORB
  • MACE-OFF
  • MatterSim
  • OMol25
  • UMA
  • G-xTB

Progress

Initial benchmarking results are being collected.
